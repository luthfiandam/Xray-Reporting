# Functional Requirements

---

# FR-001 Authentication

## Deskripsi

Pengguna dapat masuk ke sistem.

### Aktor

Teknisi

Supervisor

### Input

Username

Password

### Output

Dashboard

---

# FR-002 Equipment Management

Sistem dapat menyimpan:

- Lokasi
- Equipment
- Jenis Equipment

---

# FR-003 QR Code

Teknisi melakukan scan QR.

Sistem membuka data equipment yang sesuai.

---

# FR-004 Preventive Maintenance

Teknisi dapat membuat PM Session.

PM terdiri dari:

- Checklist
- Measurement
- Evidence
- Catatan

---

# FR-005 Checklist

Checklist mengikuti Template.

Template berbeda untuk:

- Harian
- Mingguan
- Bulanan
- Tahunan

---

# FR-006 Measurement

Teknisi dapat:

- Input manual
- Menggunakan OCR

---

# FR-007 OCR Assist

Sistem mampu:

- Crop area Generator Test
- Image Processing
- OCR
- Parsing
- Menampilkan hasil OCR

Teknisi dapat:

- Mengubah hasil OCR
- Menyimpan hasil final

---

# FR-008 Evidence

Teknisi dapat:

- Ambil foto
- Upload foto
- Hapus foto
- Preview foto
